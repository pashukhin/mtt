## What

Makes `mtt check` the single **integrity gate** and aligns the two sibling checks with it
(brainstorm-decided 2026-07-25; spec/plan in `docs/superpowers/{specs,plans}/t58-*`, three adversarial
review rounds). Addresses the 2026-07-22 integrity audit:

1. **Core — `CheckIntegrity`** (`internal/core/checkintegrity.go`): one pure entry point composing the
   existing ref sweep (`CheckRefs`) with two new detectors — a **dangling `depends_on`** sweep (a blocker
   id absent from the task set) and `DepGraph.Cycles()`. Returns an `IntegrityFinding` discriminated union;
   `IntegrityKind` is a closed vocabulary encoding hardness in the kind itself (`dangling-ref`/`dangling-dep`/
   `cycle` are hard; `unverified-ref` soft). New `DepFinding{Task, Missing mtt.TaskID}` references by identity.
   Sentinel `ErrDanglingRefs` → **`ErrIntegrity`** (exit 7 unchanged — the code now covers more than refs).
2. **`mtt check`** renders all four kinds + a `<dangling> dangling, <unverified> unverified, <cycle> cycle
   across <N> entities` summary (the `dangling` bucket folds ref+dep, so a dangling-dep-only repo reads
   `1 dangling`, never a zeroed line). **Exits 7** on any hard finding. `--json` is now a **`kind`-tagged
   union** — the ref arms keep byte-identical lowercase `carrier`/`ref`/`status` keys (`carrierJSON` carries
   explicit json tags), the dep arm is `{kind,task,missing}`, the cycle arm `{kind,cycle:[…]}`.
3. **`dep list --cycles` gates** — prints the cycles then returns `ErrIntegrity` (exit 7) when any exist,
   for CI-scripting parity with `check` (`no cycles` → exit 0; both text and `--json`).
4. **`roadmap` marks `(missing)`** — a dangling blocker gets a `(missing)` marker (text) and a
   `blocked_by_missing` JSON array (omitempty; `blocked_by` unchanged for back-compat), consistent with
   `dep list`/`show`.
5. **Docs** — the integrity framing swept across all parallel occurrences: DESIGN.md + DESIGN.ru.md
   (semantics bullet, the t1 Shipped forward-pointer, a new Shipped(t58) block), CLI_REFERENCE.md + .ru.md
   (`check`/`roadmap`/`dep --cycles` sections + the exit-code table), CLAUDE.md (core + cli), CHANGELOG.

**Out of scope (Non-goal):** duplicate-id — a stem-mismatch task file already fails the YAML load **closed**
(c15) → `mtt check` exits **1** (a load error before the sweep), not 7; documented so the two failure modes
aren't conflated.
