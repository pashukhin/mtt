# t78 — Example-flow gallery + a docs/no-code starter template

Pre-1.0 polish (Variant A). Turns the scattered, reference-shaped flow examples into a **quick-start
"pick a shape" gallery**, and fills the one missing shape with a runnable **docs/no-code** template.

Most of t78's literal card was already shipped by **t62** (the `coding`/`hierarchy`/`git-flow` templates +
FLOW_GUIDE §2/§7/§8). The real gaps were **discoverability** (nothing is a pickable menu) and **one missing
shape** (a no-code flow). This closes both — docs-heavy, no Go logic, `mtt init`'s minimal default unchanged.

## What's in it

- **`templates/docs.yaml`** — a new hosted, verbatim-installed template: a `doc` type with a **`review ⇄
  revision` loop** (two active states, a cycle). It is the only **gate-less / no-code** shape with a rework
  loop — it executes nothing (no branch, no PR, no gate), so a doc reaches a terminal on human review. The
  distinct lesson: *an active status can loop; a terminal need not be one hop away.*
- **FLOW_GUIDE `## 2b. Example flow gallery`** (EN + RU) — a single pickable table: minimal · coding ·
  docs/no-code · hierarchy · **git-flow ⚠ advanced** (caveated so it never reads as mandatory) + a pointer to
  §7 for non-code domains with gates/posts. Inserted as a **lettered §2b** (precedent: the existing §5b) so
  no section renumbers.
- **Discoverability wiring** — README quickstart pointer (EN + RU), and the gallery is the canonical
  "which to pick" home (`templates/README.md` demoted to a file list that points at it).
- **Sync surface** — `docs` added to every place that enumerates the hosted set: CLI_REFERENCE (EN + RU),
  `templates/README.md`, `templates/CLAUDE.md`; the two Go doc-comments (`templates.go`, `load_test.go`)
  reworded generically so they never drift again. `DESIGN.md` deliberately left untouched (its mention is an
  archival design-record — c23 territory — and stays true-but-non-exhaustive).

## CI honesty

- `docs.yaml` joins `TestExamplesLoadAndValidate` (loads + validates like every hosted example).
- New **`TestDocsIsNoCode`** — a *structural* guard (unmarshal, assert no `commands`/`post`/`post_defaults`/
  `events`) proving the starter executes nothing; catches any side-effecting step, not just git/gh. Verified
  by injecting a `commands:` on the publish edge → the test fails, as intended.

## Process

Spec → 3-round adversarial spec review (2 MAJOR + 1 prose MAJOR caught & fixed) → human sign-off → plan →
2-round adversarial plan review (a RU §12 edit that would have garbled the file, caught & fixed) → human
sign-off → TDD implementation → adversarial code review (APPROVE, with an independent negative test + an
end-to-end loop drive). `make check` green. No Go logic changed (`//go:embed default.yaml` and
`BuiltinNames() {"default"}` unchanged).
