## What

Task-context **environment** for gate `commands:`, edge `post:`, and **task** lifecycle-event pipelines —
the pilot's #1 friction (a gate could see only the 4-field `{{...}}` whitelist, so it had to re-query
`mtt show --json` / shell out for its own title/tags/parent/children). Per the approved spec/plan
(`docs/superpowers/{specs,plans}/t40-gate-task-context-env.md`; **1 spec round + 1 plan round + 1 impl
round**, each an adversarial fresh-subagent review). Release-gating for t60 (the ergonomic enabler behind the
`github-gated` template, t76).

1. **The env surface.** Commands now run with the task's read-only context in their environment:
   `MTT_TASK_JSON` (the whole task, the lean `toTaskJSON` shape), `MTT_TASK_CHILDREN_JSON` (children with
   `{id,type,status}` — the "all children done" roll-up gate), and scalars
   `MTT_TASK_ID/TYPE/STATUS/TITLE/PARENT/PRIORITY/TAGS`.
2. **The injection boundary is preserved — this is the crux.** The `{{...}}` template whitelist
   (`cmdContext{ID,Type,From,To}`) is **unchanged**; free text (title/tags) is **never** interpolated into the
   command string. It rides the **environment as data** — `sh` does not re-evaluate a parameter's value as
   code — the concrete answer to s007's "if a free-text field is ever exposed it must be quoted" seam: expose
   it as env, not a placeholder.
3. **`core` stays serialization-free.** `pkg/mtt` has no json tags, so the JSON blobs serialize via an
   **injected `func(mtt.Task) map[string]string`** — a CLI closure (`taskEnvBuilder`) that captures the store,
   does the children-`List`, and marshals with the CLI's `toTaskJSON`. `Transitioner`/`EventEmitter` hold the
   `envFn`, decide *when* to call it, and forward the map to the `Runner`.
4. **`core.Runner` port gains a per-`Run` `env`.** `Run`/`Compensate` take `env map[string]string`; the exec
   adapter sets it on `sh -c` (`c.Env = os.Environ() + KEY=VALUE`, sorted; **ours override** a same-named
   parent var; **NUL stripped**; nil = inherit, the pre-t40 behavior).
5. **Task events get it; note events do not** (a note is not a task — `NoteEvent` passes nil). Built only when
   there ARE commands / a configured hook (a no-gate edge or no-hook mutation pays no `store.List`).
6. **Scope.** Facet (a) — a per-invocation caller `--arg`/`--pr-body-file` value channel — is a distinct
   mechanism, split to **t77**. `by`/`why`-in-env deferred; VCS-context is a separate axis. ancestors/backlinks
   are YAGNI (not built).
7. **Docs (EN+RU).** DESIGN(+ru) `Shipped (t40)` block; `internal/core`/`internal/adapter/exec`/`internal/cli`
   CLAUDE.md; the doc-model `Runner`/`NewTransitioner` in `docs/architecture/model.go`; CHANGELOG.

  docs, + an impl-fix commit adding two regression tests). `go test -race` green; `golangci-lint` 0 issues.
- **Injection boundary broken-attempts (adversarial impl review, empirical):** a task title of
  `$(touch /tmp/PWNED); … && id` echoed **literally** (quoted *and* unquoted) — nothing executed, no file

  literal NUL is rejected at YAML load. The boundary held.
