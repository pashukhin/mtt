## What

Makes `mtt init --template <arg>` accept three source kinds and ships the git-integration flagship, per the
approved spec (`docs/superpowers/{specs,plans}/t62-init-templates.md`; 3 adversarial spec rounds + 2 plan
rounds + an impl review). Resolves the brainstorm fork toward **one minimal built-in + bring-your-own**.

1. **Core validation refactor** — `checkDecoded(yc)` factors `Load`'s post-overlay provider checks
   (`checkPrefixes` incl. the letters-only shell-safety prefix rule + `parseCommandTimeout`); `Load` routes
   through it and stays **byte-identical** (overlay / `Author` / tighten-only `require` untouched;
   `Config.Validate` is NOT on the `Load` path — pinned by `TestLoadDoesNotRunConfigValidate`).
   `ValidateTemplateBytes(data)` = single-doc decode → `checkDecoded` → `Config.Validate` (init owns the
   domain check for an untrusted template only).
2. **`--template <name|path|url>`** — a pure `ClassifyTemplate` resolves by shape: a bare name → the sole
   embedded built-in `default`; a **file path** or **`https://` URL** → an external config installed
   **verbatim** (no `{{.Name}}` render) after a **fail-closed** validation. A URL fetch is behind an
   injectable `http.RoundTripper` (**https-only** incl. redirects via `CheckRedirect`, ~30s timeout, ~1 MiB
   cap, non-200 error) and requires an interactive **confirm** (`--yes` skips; a non-TTY without `--yes` is
   refused — no silent remote fetch). Untrusted config-as-code → a loud **review-before-first-move** notice
   after an external install (init runs nothing). `init --json` gains `source` (`builtin:`/`file:`/`url:`);
   `--name` is ignored for external (with a stderr note).
3. **`templates/` dir + de-embed** — only `default.yaml` is compiled in; `coding.yaml`/`hierarchy.yaml` and the
   new **`git-flow.yaml` flagship** (a generalized, self-documenting derivative of this repo's dogfood flow —
   branch → agent review → human sign-off → PR → deliver, every external assumption gated or stated) are
   hosted files, URL-fetchable. All `--template coding|hierarchy` consumers migrated to the file-path source
   (11 testscripts + ~9 Go test files via `initHierarchy`/`hierarchyTemplate` + the demo).
4. **Machine→human ordering** — the flow's review-stage descriptions (dogfood config **and** git-flow.yaml)
   now state "agent gate first, human sign-off strictly after" explicitly (post-sign-off user directive).
5. **Docs (EN+RU)** — CLI_REFERENCE / README / DESIGN (a Shipped(t62) note) / FLOW_GUIDE, `demo/README`,
   CLAUDE.md (cli + yaml adapter + new `templates/`), CHANGELOG (with the `--template coding|hierarchy`
   breaking note).
